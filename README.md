Entry for the make.fun Two-Sentence Horror bounty: a Node 22 TypeScript program that writes exactly one horror story — two sentences, 158 characters — to `/output/entry.txt`. A grandson holds his grandfather's hand through the night in a coma the nurse calls a mercy; every time he lets go, the fingers tighten around his. The horror is never explained, only implied.
